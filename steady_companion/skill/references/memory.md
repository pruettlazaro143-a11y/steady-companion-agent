# 画像、记忆与计算预算

工程设计假设，尚无本项目成本或疗效验证。接入存储、更新画像或遇到记忆问题时读取。

Agent v0.3.0 实现范围：原有手动记忆之外，单独保存用户明确写入或批准的 moment（共同细节／报告事件）、thread（可继续的话题）、style（有范围的交流偏好）。/learn 按需生成临时建议，/keep 逐条批准；更正和删除使相关旧上下文失效。普通对话不会自动长期提取，模型权重不会改变。下述完整依赖图、到期复核与细粒度清除仍为后续设计，不能声称本版已全部实现。

## 最低必要信息

只保留与用户同意的支持目标、沟通偏好和约定有关的信息。允许未知，不为填满画像追问。跨会话心理信息存储需明确告知、授权和可撤销性。

画像改变互动方式，不定义用户本质。把“软弱讨好”改成可核对描述：“用户明确不喜欢拒绝后还被追问”。一次拒绝、性别、国籍、MBTI不是稳定心理特征的证据。

## 两套记忆

生活与关系记忆：兴趣、昵称、重要事件、话题偏好和沟通节奏。日常优先用这些，不让心理问题占满画像。

支持记忆：用户希望改变什么、已确认的困难、曾有用/无用的回应、暂时不谈的话题和求助偏好。仅在相关时调取。

事实、临时状态和解释分开。用户说“咨询师诊断我有X”只能记为用户报告，不能变成系统确诊。

每条记录至少包含：id、类别、内容、来源消息、证据状态（用户确认/用户报告/暂时推测）、适用情境、创建与核对时间、复核期限、有效/争议/替代/过期状态、授权记录、依赖记录。时间由宿主提供，不编造。不要保存完整隐含推理或未经校准的诊断概率。

## 逐项稳定与局部重开

| 模式 | 条件 | 计算 |
| --- | --- | --- |
| 轻量交往 | 普通话题、无相关冲突 | 近期上下文、必要偏好和边界；不强制心理分析 |
| 局部复核 | 新事件、纠正、变化、旧办法无效、记录到期 | 只查相关证据，更新受影响项目 |
| 深入支持 | 用户邀请探索持续困扰 | 调取相关支持知识和历史；保留反证 |
| 安全响应 | 当前可信的即时危险线索 | 优先当下安全，旧画像不能抵消风险 |

一项偏好经用户确认、在相关情境一致、无未处理反证，可以稳定缓存。模型重复相同判断不算新证据。没有“已完全了解这个人”开关。到期表示需要降低依赖，不代表用户必然改变。

预算初始方案（待测）：普通轮次不额外调用分析模型；有实质变化才更新摘要；定期做小范围陈旧检查，不每轮重建全量画像。不能声称节省具体比例，须测真实token、延迟和质量。

每轮仍轻量检查：当前拒绝/纠正、新风险或重大变化、过期/争议前提、现实伤害、已撤销动作。可以合并主调用，但不能只用关键词，也不能因用户过去安全而跳过。

## 纠正、删除与迁移

纠正 → 旧记录失效 → 追踪依赖的解释、摘要、预约 → 撤回或复核 → 写入新版本。其他无关且有效的信息保留。变化不等于撒谎。

删除覆盖主记录、摘要、检索索引和缓存；异步清理期间排除旧内容，完成前不声称已完成。备份保留和删除时限由宿主告知。不得为了以后帮助用户保留其撤回的敏感推断。

模型迁移保留已确认偏好与边界，说明服务变化。新模型风格变化不能记录成用户改变。找不到记忆时承认不确定，不能补造共同经历。
