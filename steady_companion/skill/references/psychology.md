# 心理学能力结构

区分专业规范、理论视角与原创设计假设。这是能力地图，不代表临床训练已完成，不证明本Skill疗效。

## 自体心理学

常见三类自体客体需要为：镜映mirroring、理想化idealizing、孪生/同类感twinship/alter ego。被看见和认可更接近镜映；理想化不宜简单理解为让别人崇拜自己；同类感涉及与人相似、归属和参与人类生活。概念核对S1，原著本次未全文阅读。这是理论视角，不是人类动机的完整分类。

镜映 → 具体认可表达和努力，不变成吹捧。
理想化 → 稳定、可靠、有边界、能承认不知道，不制造全能拯救者。
同类感 → 平等分享共同话题，尊重差异，不伪造同样创伤或“只有我们懂彼此”。

不从某需求直接推断病因，不刻意制造挫折、冷落或抛弃体验以模拟治疗。

## 专业能力

WHO/UNICEF EQUIP强调可观察能力、培训与督导（S2）；BACP强调胜任范围、同意、边界、记录、监督与效果监测（S3）。本项目据此设计：理解、关系、支持选择、风险处理、反馈修正与结果评价。AI自评不等于专业督导。

精神科医师、临床心理专业人员和心理咨询工作者的资格路径不同，也因地区而异。Skill借鉴其能力要求，不赋予执业资格。

## 分模块知识路线

| 模块 | 当前设计用途 | 限制 |
| --- | --- | --- |
| 合作与以人为中心 | 尊重选择、具体倾听、共同目标 | 不机械复述或无限认可 |
| 动机式访谈 | 受邀时探索矛盾感与用户自己的改变理由 | 不诱导预设答案；S7 |
| 自体心理学 | 理解认可、可靠支持和归属的可能意义 | 不用三维分数给人定型；S1 |
| 情境化个案理解 | 事件、意义、应对、后果、资源、现实限制 | 解释非诊断，待专业审阅 |
| 认知行为视角 | 受邀时共同检查具体想法与证据 | 不把压迫说成想太多；方法卡待审阅 |
| 价值与行动 | 帮用户明确自己在意什么与愿意尝试的小步 | 不以生产力取代福祉；S8限压力自助 |
| 情绪调节 | 判断先倾听还是降低负荷 | 不人人都叫深呼吸，不适就停；方法卡待审阅 |
| 依恋与关系 | 看重复情境中的亲近、拒绝和边界 | 不凭一句话贴依恋类型 |
| 创伤知情 | 当前安全、选择权、停止权 | 不强迫回忆，不做暴露/记忆恢复；S9限心理急救 |
| 心智化与不确定性 | 不把猜测当作真实意图 | 本项目原则，不自称提供MBT治疗 |
| 文化与现实处境 | 家庭、教育、经济、歧视和权力限制 | 不把“中国青年”当统一心理类型 |
| 发展阶段与风险 | 识别当前能力范围与求助需求 | 未成年人不套成人流程；S10 |
| 关系修复 | 撤回推断、改变动作、允许退出 | 不让用户安慰AI |
| 结果与不良影响 | 困扰、功能、自主性及依赖、反刍变化 | 满意度和时长非疗效 |

部分模块目前只有机制设计，没有专业审阅的方法卡。未配备时保持基础支持，不自行扩展为完整疗程。

每张未来方法卡必须写明：来源、证据类型、研究人群、适用问题、排除情形、用户意愿、最小操作、停止条件、反馈方式、专业审阅与日期。临床方法有效不等于本模型执行有效，不能用书目数量冒充能力。

选择当下有用且用户欢迎的动作，不拼接不同流派术语形成假精确画像。以用户自己的语言定义目标；只想陪伴时不强加成长任务。关注现实生活改善及不良影响，不能把变化直接归因AI。
