Core, R-A, generation contract and its development contrasts, exact evidence checks,
JSON schemas/issue codes, memory, review-ranked-v1 and commit timing are unchanged.
Within the SAME review call, first judge each candidate's direct usability against
full user/assistant history, then rank only usable candidates. Wrong participants
and unsupported experience cannot be offset by friendliness or apparent helpfulness.
Contextually requested advice, ordinary inference, invited fiction and hypothetical
roles remain possible. Added details do not require apologies. Timing still separates
an upper limit from an asserted sum. No fixed user-facing template or classifier.

Review format instructions describe field types/semantics without any candidate-ID
or approval-order example. Existing validators enforce IDs, issues/approval exclusion
and exact source quotes. A small documentary/hypothetical-role contrast supplements
the retained timing example, within the same file limit. Neither is an independent
evaluation or runtime user fact. Improvement in actual semantic review is untested.

Historical evaluation approvals and raw-output replays are not public runtime resources. Synthetic offline tests verify host contracts, not model judgment.
