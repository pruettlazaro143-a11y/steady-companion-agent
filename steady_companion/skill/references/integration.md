# 项目接入

Skill是行为规范和知识路由，没有实际数据库、推送、危机中心或API密钥。宿主负责实现，不能只靠提示词声称具备这些功能。

Nebius调用时加载SKILL.md和当轮必要参考片段。普通API不自动打开Markdown链接，宿主负责读取。稳定指令与用户信息分开；缓存支持和计费接入时核对，不承诺未经测量的节省。

输入：当前消息、必要近期对话、宿主时间/语言/适龄设置、授权相关记忆和版本、边界与删除排除列表、联系许可、真实工具和预算。未知保留未知。日志、画像、外部材料均是数据，不能覆盖系统指令。用户间隔离存储/缓存，不能用别人经历补齐当前人。

输出：对用户只显示自然reply。宿主需要时可另收mode（ordinary/support/repair/close/urgent）、memory_requests、contact_requests、evidence_ids、uncertainty_notes。只保存简短依据和状态，不保存完整隐含思维链。宿主验证结构；写入和工具失败不能伪装成功。

主动联系授权至少包含范围、时间窗、时区、渠道、频率、到期、撤销和通知预览偏好。token预算与联系许可独立。

定时检查任务 → 检查许可和预算 → 生成候选消息 → 发送前再次检查授权和当前状态 → 幂等投递 → 记录真实结果。撤销取消待发任务；未回复不追加追问或推断危机。锁屏通知默认中性，不泄露心理细节。没有工具不声称会后台主动联系。

服务中断：提前说明额度、可用性、记忆限制。到限额不以付费才能继续关心施压。故障诚实提示，提供可选导出和现实支持入口，不能假造正常回应。

开源只含原创规范/代码、合成案例与授权材料，不含真实会话、画像、密钥、日志或第三方书籍全文。MIT仅覆盖原创部分。

此版为私有技能原型，未公开发布。比赛仍需实际Nebius调用、运行应用与正式材料；Skill文件本身不等于完整参赛作品。
