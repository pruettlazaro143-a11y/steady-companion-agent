| Fix | Reproduction mechanism | Change / observable test |
|---|---|---|
| F1 | Mood clause followed by a real pause stayed unclassified | Parse unquoted own-speech clauses; a compound work-topic pause reaches the check, a conflicting draft is withheld and old history remains unchanged. Reported, conditional and negated pauses do not create boundaries. |

No changes to memory authorization, model routes, persona, main reply schema, recovery counts or default flags. New checks consume the existing budget; budget/timeout/cancel paths do not show unchecked drafts or commit failed responses.

Remaining gaps: finite surface recognition misses implicit references and unfamiliar paraphrases; scoped personal authorization is deliberately narrow; ambiguous utterances may retain a boundary until clearer input. Question intent/relevance is not solved by regex. The semantic checker can itself misjudge, and more triggers can add cost or withhold acceptable drafts. Local topic matching and metadata filtering cannot prove all material appropriate. No new real-model, naturalness or psychological-effect evidence.
