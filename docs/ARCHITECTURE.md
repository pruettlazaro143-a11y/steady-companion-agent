# Architecture

1. Model access: transport, explicit service/model/parameters and separate credentials.
2. Local topic materials: named/alias-relevant bounded excerpts with provenance; no automatic web search.
3. Authorized memory: explicit records, ordinary scoped auto records, recent actual speaker-tagged context. Current corrections override stale records.
4. Versioned product core: common stance, R-A and safety, plus optional host scope enforcement.

The generator sees real history and relevant untrusted data. The daily companion path validates visible output locally. The separate checked path validates candidate structure/exact evidence, filters eligible candidates and requires review. Neither exact evidence nor review approval proves factual accuracy or clinical safety.

Optional InteractionState interprets a complete utterance before committing events. Supported pauses survive ambiguous/quoted/withdrawn invitations. Permissions specify operation and object: problem clarification does not grant personal-history collection. Selective check signals include supported boundaries, investigation moves and same-topic follow-ups. Signals request a bounded check; they are not automatic semantic verdicts. A failed/unknown required verdict never reaches normal reply/history/memory commit. Calls share the existing Usage ledger.

Topic retrieval can support ordinary sharing. It filters paused-topic clauses and labelled personal-assessment material; permission for content is separate from permission for assessment. This is a limited lexical gate, not general relevance understanding. Only actual named library material is retrieved. Public fixtures add synthetic local documents; the bundled topic library is deliberately small.

State and recent move summaries are volatile and bounded. They do not expand persistent memory authorization, send proactive messages, use tools or infer a profile. Both interaction flags default off. Full core/R-A/safety and underlying model/response contracts are unchanged by the dev14 scope fixes.
